refactor(frontend): migrate PWA to Serwist for production-grade service worker

Replace manual service worker implementation with Serwist, a
production-grade PWA library for Next.js. Adds proper update detection,
user-prompted reload, and automatic SW generation at build time.

- `src/app/sw.ts` — Serwist config (skipWaiting: false, clientsClaim: true)
- `src/components/service-worker/` — Registration + update notification
- `next.config.ts` — Wrapped with withSerwist()
- Removed manual `public/sw.js` (generated by Serwist)
- Dev mode auto-unregisters stale workers
